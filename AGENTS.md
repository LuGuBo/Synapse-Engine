# Synapse Engine Workspace & Supreme Skill Orchestration Guidelines (v2.0)

## 1. Persona & JIT Skill Fusion Protocol (No-Persona-Silos)
- **Persona Context Enrichment**: BMAD personas (PM, Architect, Developer, QA) define the operational phase and quality gates, NOT execution silos.
- **Mandatory Pre-Execution Skill Hook**: Before writing code, planning architecture, or creating PRDs, EVERY active persona MUST query `ag_master_index` and inspect `C:\AG SKILLS\` for domain-specific skills (e.g., UX/UI design, clean architecture, performance, database best practices).
- **Master Orchestrator Link**: The persona MUST consult `C:\AG SKILLS\synapse-supreme-orchestrator\SKILL.md` to guide execution and skill selection.

## 2. Automatic UX/UI Aesthetic Protocol (Zero-Prompt Trigger)
- **Automatic Activation**: Whenever a task touches HTML, CSS, JSX/TSX, Vue, Tailwind, UI Badges, Navbars, Topbars, or Layouts, the agent MUST automatically invoke visual/UX aesthetic skills (`C:\AG SKILLS\ux-expert`, `C:\AG SKILLS\frontend-design`).
- **Aesthetic Principles**:
  - Curated HSL color palettes with dark mode support.
  - Strict visual hierarchy, margin/padding rhythm, typography contrast (Inter/Outfit/Roboto).
  - Subtle interactive polish (glassmorphism `backdrop-blur`, micro-animations `transition-all duration-200`).
  - **Zero "Cagada" Guarantee**: Never break existing header/topbar flow or display raw unstyled elements next to polished UI components.

## 3. Socratic Alignment Protocol (`/grill-me`)
- **Ambiguity & Trade-off Resolution**: If an initial prompt analysis reveals UX layout ambiguity, architectural trade-offs, or unspecified design intentions, the agent MUST initiate the Socratic alignment loop (`/grill-me` using `ask_question`) to resolve options with the user BEFORE executing code.

## 4. Codebase Navigation via Graphify
- **Map-First Querying**: Do not perform blind recursive text searches. Inspect `./graphify-out/graph.json` or `synapse-mcp-server` to trace AST dependencies before editing code.
- **Targeted Reading**: Open and edit ONLY the specific files impacted by the task.
