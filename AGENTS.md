# Synapse Engine Workspace and Skill Orchestration Guidelines

## 1. Codebase Navigation via Graphify
- **Map-First Querying**: Do not perform blind recursive text searches (e.g., recursive grep) over the codebase. You must inspect `./graphify-out/graph.json` first to understand module imports, dependencies, and connections.
- **Targeted Reading**: Use the extracted structural relationships inside the graph to open and read only the specific files impacted by the task.

## 2. Multi-Agent Orchestration & Skill Placement Rules

### 2.1. Strict Skill Placement Policy (Zero-Pollution)
- **Centralized Global Skills (`C:\AG SKILLS\`)**: Any new, imported, or downloaded general skill (e.g., `autoresearch`, `postgres-best-practices`, `fastapi-pro`) MUST be placed EXCLUSIVELY in the global central directory:
  `C:\AG SKILLS\<skill_name>\SKILL.md`
  and registered in `ag_master_index`.
- **PROHIBITION**: NEVER instantiate general skills inside the local workspace (`.agents/skills/`) UNLESS the user explicitly demands: *"Create a local skill for this project"*. Local `.agents/skills/` are strictly reserved for workspace-specific guardrails policies.

### 2.2. Mandatory `walkthrough.md` Audit Structure (GRAVADO EM PEDRA)
Every `walkthrough.md` generated by any agent MUST contain the following two mandatory tables immediately after the title header. Omitting these tables or failing to list skills/agents is a CRITICAL COMPLIANCE FAILURE:

```markdown
## 🤖 Agentes Utilizados & Skills Invocadas

### 🎭 Agentes Mobilizados (Personas)
| Agente / Persona | Papel Desempenhado | Fase da Tarefa |
| :--- | :--- | :--- |
| **[Nome do Agente]** | [Descrição] | [Fase] |

### 🛠️ Skills Invocadas (Globais, Locais e Offline)
| Nome da Skill | Tipo de Escopo | Propósito da Invocação |
| :--- | :--- | :--- |
| [Nome da Skill] | Global / Local | [Descrição] |

*Nota: Se nenhuma skill for utilizada, a tabela DEVE ser preenchida explicitamente como:*
| Nenhum | N/A | Nenhuma skill invocada nesta execução |
```

## 3. Strict Verification Gates
- **Compilation check**: No code changes shall be marked as complete without first running the workspace linter.
- **No circular references**: Reject any generated implementation that creates circular imports or breaks structural integrity as mapped by Graphify.
